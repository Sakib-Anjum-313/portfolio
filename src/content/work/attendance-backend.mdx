role: Designed the architecture and backend
stack: [FastAPI, PostgreSQL, Alembic, Nginx, AWS EC2]
device: ZKTeco SenseFace 2A

category: [Backend, Integrations]

problems:
  - problem: Device re-sends the same upload
    answer: exact replays deduplicated; device gets OK only after the batch commits.
  - problem: Accidental double scan
    answer: kept as evidence; counts as checkout only after the shift's minimum gap.
  - problem: Terminal offline, uploads hours later
    answer: late punches recalculate the finalized day.
  - problem: HR already corrected a day
    answer: the override stays; the day is flagged "Review required".
  - problem: Shift rules change
    answer: immutable, effective-dated shift revisions; past days keep their rules.
  - problem: Employee leaves
    answer: identity disabled or deleted on terminals via a command queue.
  - problem: Privacy
    answer: no face or fingerprint templates or photos stored in the ERP.
design: "terminal → PUSH receiver → immutable raw event + work item (one transaction) → single advisory-locked worker → daily result → 7 reports. Bounded retry, crash recovery, heartbeat."
decisions:
  - "One locked worker instead of many: correctness first; multi-worker scaling waits until it can be proven safe."
  - "Raw evidence is immutable; everything else is derived and can be recalculated."
  - "Verify, don't trust: an AI-suggested device-authentication flow was checked against the device documentation and dropped before implementation because the hardware doesn't support it."
